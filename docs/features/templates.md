# Flow Templates

Get started quickly with pre-configured operational workflows.

## Available Templates

- **Assistant Basic**: A simple but effective starting point with Chat Input, Prompt Template, Agent, and Chat Output.
- **GitLab MR Reviewer**: Fetches changes from a GitLab Merge Request and provides a comprehensive code review.
- **SQL Analyst Agent**: Connects to an MSSQL database to answer natural language questions with data.
- **Elastic RAG Assistant**: Implements Retrieval-Augmented Generation using Elasticsearch and embedding models.
- **API Incident Investigator**: Helps SREs investigate incidents by correlating logs and metrics from HTTP APIs.

## How to Use

1. Navigate to the **Home** dashboard.
2. Browse the **Flow Templates** section.
3. Click **INITIALIZE** on any template to create a new flow based on that schema.
4. The editor will open with all nodes and edges pre-connected.
5. Configure the necessary credentials (API keys, DB connection strings) in the node config panels.
