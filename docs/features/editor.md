# Flow Editor

The N2FLOW editor provides a visual interface for building complex AI workflows.

## Key Features

- **Drag-and-Drop**: Easily add and connect nodes.
- **Node Types**: LLM, tools, agent nodes, and utility nodes.
- **Live Preview**: See the output of your flow as it executes.
- **Topological Layout**: Automatically organize your flow.

## Technology

Built with `@xyflow/react` and `dagre` for graph management and layout.
